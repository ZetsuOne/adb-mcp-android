# Local binaries

Put Android **platform-tools** here:

```text
bin/platform-tools/adb.exe   # Windows
bin/platform-tools/adb       # Linux / macOS
```

Download from [Google platform-tools](https://developer.android.com/tools/releases/platform-tools).  
USB vendor drivers stay outside this repo.

The folder `bin/platform-tools/` is gitignored so large OEM/Google binaries are not committed.
